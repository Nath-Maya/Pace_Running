# Pace Running – Zonas de Paso Team Warriors

App web sencilla (HTML + CSS + JavaScript, sin frameworks) con los resultados del Test de 20' de zonas de paso del Club Deportivo Team Warriors (tests de febrero y octubre 2026).

- Buscador de atletas con autocompletar.
- Selector de zona (Z1–Z7) y rango (Baja / Media / Alta) con los rangos para configurar el reloj.
- Comparación entre tests con el estado oficial del entrenador.

## Cómo usar

Abre `web/index.html` en el navegador. No necesita servidor ni instalación.

Más detalles (estructura y cómo agregar un test nuevo) en [web/README.md](web/README.md).
